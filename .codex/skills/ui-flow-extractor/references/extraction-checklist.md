# UI Flow Extraction Checklist

## 1) Route Inventory
- Route path
- 접근 조건(로그인/권한)
- 화면 목적

## 2) Component Decomposition
- Container 컴포넌트
- Presentational 컴포넌트
- Shared UI 컴포넌트
- Context/Store 의존성

## 3) UX Action Map
- 사용자 액션
- 전처리/검증
- 상태 변화
- API 메서드/엔드포인트
- 성공/실패 UX

## 4) Contract Signals
- 스펙 존재 여부
- 필드명/타입 차이
- 에러 처리 방식 차이

## 5) Decision Flags
- 즉시 확정 가능
- 사용자 승인 필요
- 스펙 신규 제안 필요
